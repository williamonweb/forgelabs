# Forge Labs

Site institucional da Forge Labs, desenvolvido em Next.js.

## Rodar no computador

Requer Node.js 22 ou superior.

1. Execute `npm install`
2. Execute `npm run dev`
3. Abra `http://localhost:3000`

## Publicar

O projeto está pronto para ser enviado a um repositório novo no GitHub e importado na Vercel.

Rotas disponíveis:

- `/` — página inicial
- `/servicos` — serviços
- `/projetos` — portfólio
- `/sobre` — sobre a empresa
- `/contato` — formulário com envio pelo WhatsApp

As imagens e a identidade visual estão dentro da pasta `public`.
